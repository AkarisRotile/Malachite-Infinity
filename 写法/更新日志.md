## 2026-09-01 ｜ 首测反馈修复（特效过曝/巨型光带）

**用户测试反馈**：① 武器贴图还是灾厄原版；② 特效是屏幕上乱闪旋转的超巨型长条光带；③ 弹幕没变化。

### 根因分析
1. **超巨型光带**：特效绘制误用 `TextureAssets.MagicPixel`（tModLoader 内部纹理，尺寸不可控），按 1x1 写的缩放被放大 → 巨型光带；叠加 additive 加色混合 → 过曝乱闪。
2. **武器贴图/弹幕未变**：自建武器是**独立新武器**（需砍树重新获取）；旧档持有的灾厄 Malachite 仍走灾厄路径（旧贴图、旧弹幕），符合"双轨兼容"设计，非 bug。

### 修复
| 文件 | 改动 |
|---|---|
| `Core\AdditiveLayer.cs` | 新增 `Pixel` 共享纹理（自建 `Textures/Pixel.png` 1x1，尺寸绝对可控），替代 MagicPixel |
| `Projectiles\MalachiteProj.cs` | 光带 34x3 → **14x1.8**；双层亮点 3.2/5.5 → **2.2/3.4**；alpha 下调（0.85→0.65） |
| `Projectiles\MalachiteBolt.cs` | 主光带 64x2.6 → **36x1.8**；尾光 30→18；白芯 48→26；alpha 下调 |
| `Projectiles\MalachiteProjectiles.cs` | 浮游剑阵光羽 30x2.6 → **13x1.6**；白芯 21→9；亮点 3.2→2.0；alpha 下调 |

### 测试须知（重要）
- **新武器获取**：砍树掉落的是新的"孔雀翎"（自建武器），旧档中已有的灾厄 Malachite 不会自动替换——需重新砍树或作弊刷取体验新贴图与新弹幕
- **双轨行为**：手持自建武器 → 本模组特效弹幕；手持灾厄武器 → 灾厄原版弹幕（兼容旧体验）
- 确认 ModSources 同步时包含 `Textures\MalachiteItemGame.png` 与 `Textures\Pixel.png`
