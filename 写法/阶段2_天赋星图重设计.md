# 阶段 2：天赋星图重设计（v1 实施规格 · 决策已锁定）

> 更新：2026-09-02 ｜ 前置草案 v0 见 git 历史
> 本文件为**当前实施依据**；所有决策均经用户拍板（D6~D12 记录见 §7）。

---

## 0. 本次决策汇总（用户拍板，2026-09-02）
1. **对话 UI 冻结**：MalachiteUI 对话/History 区不改不动。
2. **旧 19 节点效果全部停用**：本次为"纯加点化"，攻击曲线重调，不再有旧星图技能效果。
3. **小节点 = 五轨**：攻击 / 穿透 / 攻速 / 暴击 / 并发弹幕数量。
   - 附加规则：**总暴击 > 100% 时，溢出部分按比例增幅最终伤害**（默认 每溢出 1% → 终伤 +0.5%，可调）。
   - **并发弹幕轨升级单价高于其它轨**。
4. **技能点**：不同 Boss 首杀各给一次（复用 `MalachiteProgress.DefeatedBosses`）。
5. **进度**：无灾厄可达满阶（灾厄锚点随摘除层一并移除，全原版阶梯）。
6. **旧档**：天赋清空重来 + 按已击杀 Boss 数一次性补偿技能点。
7. **灾厄兼容层彻底摘除**：本 mod 完全独立、不再服务灾厄孔雀翎；灾厄"孔雀翎"与本 mod"孔雀柳刃"互不干涉。
8. **大节点（技能）先不定**：模型预留扩展位，UI 预留区域，等后续设计。

## 2. 新天赋数据模型（v1）

### 2.1 存档（角色档，`MalachitePlayer.SaveData/LoadData` 升级）
```
talentVersion: int              // =2，旧档无此键 → 触发迁移（清空+补偿）
skillPoints: int                // 技能点余额
trackAttack, trackArmorPen, trackAttackSpeed, trackCrit, trackVolley: int   // 五轨等级
obtainedMalachite / dialog 等原有键保留
```
- 世界档：`defeatedBosses` 升级为技能点唯一权威源；修 `!Main.dedServ` 守卫（专用服也登记）+ MP 权威（仅服务器写、客户端同步只读）。

### 2.2 默认数值表（v1 草案，全部可调，数值对齐时逐项确认）
技能点发放（不同 Boss 首杀）：
| 强度档 | 点数 | 覆盖（原版） |
|---|---|---|
| 普通 Boss | 1 | 克眼/邪恶×2/骷髅王/蜂后/史莱姆王/鲨鱼公爵(可选) 等 |
| 进阶 Boss | 2 | 机械三王/世纪之花/石巨人/拜月教 |
| 终局 Boss | 3 | 月总 |
| 事件首领（可选） | 1 | 双月王/火星UFO/旧日军团(按实现难度决定是否计入) |

小节点轨（每级效果 / 单级成本 / stage cap 建议）：
| 轨 | 每级效果 | 成本曲线（默认） | 等级 cap（stage） |
|---|---|---|---|
| 攻击 | 最终伤害 +4% | 1 + 当前级×1 | min(3+stage, 12) 左右 |
| 穿透 | 护甲穿透 +3 | 同上 | 同上（数值再校） |
| 攻速 | 攻击速度 +2.5% | 同上 | 同上 |
| 暴击 | 暴击率 +3%（暴击>100% 溢出按 0.5%/1% 增幅终伤） | 同上 | 同上 |
| 并发弹幕 | 每次使用 +1 道弹幕（扇形齐射） | **（2 + 当前级×2）×2**（单价更高） | 上限低于其它轨（默认 max 5） |

> 攻速轨与基础攻速相乘后仍走 `UseSpeedMultiplier` clamp（0.1~5 现规则保留）。
> 暴击溢出公式默认：`finalMult = 1 + max(0, totalCrit-100) * 0.005`；totalCrit 含饰品等。

### 2.3 求值：`TalentProfile`（只服务原生孔雀柳刃）
```
struct TalentProfile { dmgMult; armorPen; speedMult; critBonus; volleyBonus; }
TalentEvaluator.Build(player, stage, tracks) → TalentProfile
```
武器（PeacockWillowBlade）与弹幕命中层只读 Profile；旧 `ActiveSigils.Contains(id)` 全部删除。

## 3. 进度重锚（纯原版阶梯草案）
灾厄锚点删除后，stage 0~13（或收敛到 0~11）用原版里程碑：0 无 / 1 克眼 / 2 邪恶首领 / 3 骷髅王 / 4 肉山 / 5 机械三王任一 / 6 世纪之花 / 7 石巨人 / 8 拜月教 / 9 月总 / 10~13 需要**无灾厄自足锚点**：
- 草案：以 `MalachiteProgress` 自记里程碑实现（无需新 Boss）——
  10 = 月总后任意原版事件完成数 ≥3（火星/双月/旧日军团）或 击败月总后击杀月总相关仆从若干，选取实现最简者；
  11~13 = 本模组「试炼」档（如累计击败 月总+事件冠军 组合次数 / 全 Boss 击杀率），具体规则数值对齐时定稿。
> 若你希望 stage 上限就是月总（9 档封顶、砍掉 10~13 与灾厄同等内容），也只需说一声——重锚表按"档数"重构即可。
