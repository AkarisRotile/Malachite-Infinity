# 脱离 CalamityMod 方案（可成长的孔雀翎）

> 目标：让模组逐步摆脱对灾厄（CalamityMod）的运行时与编译期依赖，最终可在无灾厄环境下独立运行。
> 现状版本：v1.5.3 ｜ 编写日期：本次会话

---

## 一、依赖全景（44 处引用，已全量审计）

### 1. 编译期硬依赖（`using CalamityMod`，无灾厄无法编译）

| 文件 | 用到的灾厄类型 | 说明 |
|---|---|---|
| `Items\PeacockModifier.cs` | `player.Calamity()`、`StealthStrikeAvailable()`、`proj.Calamity().stealthStrike`、`DownedBossSystem.*` | 潜伏攻击判定 + 阶段判定 |
| `Players\MalachitePlayer.cs` | `proj.Calamity().stealthStrike`×3、`CalamityMod.Particles`（GeneralParticleHandler/SparkParticle）、`DownedBossSystem.downedPlaguebringer` | 命中逻辑、粒子 |
| `Projectiles\MalachiteProjectiles.cs` | `proj.Calamity().stealthStrike`×4、`CalamityMod.RogueDamageClass`、贴图 `"CalamityMod/Projectiles/Rogue/MalachiteProj"`、`DownedBossSystem.downedPlaguebringer` | 弹幕接管、伤害类、贴图 |

| `Core\EffectLimiterSystem.cs` | `CalamityMod.Particles` | 粒子限流系统 |

### 2. 运行时软依赖（`MalachiteCache` TryFind 缓存，灾厄缺失时静默失效）

| 缓存项 | 灾厄资源 | 缺失后果 |
|---|---|---|
| ProjType / BoltType / StealthType | 灾厄原版武器 Malachite 的 3 种弹幕 | 武器发射逻辑退化 |
| MalachiteItem | 灾厄武器 Malachite | **整个模组失去载体**（GlobalItem 只作用于它） |
| PlagueBuff / GlacialState / HolyFlames / BrimstoneFlames | 灾厄减益 | 特效减益缺失（部分已有原版兜底） |
| Fist1/Fist2/Slash1/Slash2 | 灾厄 Boss 弹幕（擎星者/灾厄之拳/斩击） | `IsNativeBossProj` 联动失效 |

### 3. 玩法机制依赖
- **潜伏攻击**：`player.Calamity().stealth` 潜伏值、`StealthStrikeAvailable()` 判定、`proj.Calamity().stealthStrike` 弹幕标记——借灾厄盗贼职业机制。
- **伤害类**：`RogueDamageClass`（灾厄盗贼）用于浮游剑阵。
- **进度锚点**：`GetMalachiteStage()` 的 stage 8~13 与 10 个天赋解锁绑定灾厄 Boss（歌莉娅/亵渎天神/吞噬者/亚龙/星流/至尊女巫/噬魂幽花/极地之灵/利维坦/星神游龙）。

### 4. 内容联动
- `IsNativeBossProj`：本模组 GlobalProjectile 接管灾厄 Boss 的拳/斩弹幕（奇特性联动），脱离后需废弃或改为可选。
- 美术：`OrbitingMalachiteProj` 直接引用灾厄贴图路径。

## 二、目标架构

**完全自给自足 + 可选兼容**（灾厄在 → 沿用灾厄内容；灾厄不在 → 全功能运行）：

1. **自建武器** `MalachiteItem`（ModItem），替代对灾厄 Malachite 的 GlobalItem 寄生。
2. **自建弹幕**：MalachiteProj / MalachiteBolt / MalachiteStealth（行为等效自研，不复制灾厄源码）。
3. **自建进度系统**：本模组 `DownedBossSystem`（ModWorld 存档），灾厄缺失时用原版/自设锚点。
4. **自建潜伏系统**：本地潜伏值与 stealthStrike 标记（或改机制，见决策 D3）。
5. **自建减益**：瘟疫/冰河时代/神圣之火/渊火（ModBuff 或原版替代）。
6. **自建粒子**：Dust 实现替代 SparkParticle。
7. **自建贴图**：武器/弹幕占位图。

## 六、决策记录（用户确认）

- **D1** 渐进式：先隔离层，最终完全独立。
- **D2** 天赋系统重构（MMORPG 式）：
  - **大节点**：技能节点，有启用上限，给予武器新的特效/增强/改变攻击方式。
  - **小节点**：属性节点，每击败一个不同 boss 给若干技能点，消耗技能点增强武器（加攻击/穿透/攻速等）。
  - 进度重锚与天赋重构一起在阶段 2 完成。
- **D3** 自建潜伏条 + 简易 HUD。
- **D4** 武器贴图由用户自绘；**弹幕全部用纯特效实现**（光效/粒子，无贴图依赖），后期用户再补美术。
- **D5** 直接废弃 IsNativeBossProj 联动。
