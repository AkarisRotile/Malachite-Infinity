## 三、当前架构（解绑后）

### 武器
- **孔雀柳刃（PeacockWillowBlade）**：本模组独立武器。自带：阶段成长（ProgressSystem.GetStage）、潜伏（StealthSystem）、射击（MalachiteProj/Bolt）、浮游剑阵、tooltip、右键对话。ModItem hooks 注意签名**无 Item 参数**（ModifyWeaponDamage(Player, ref StatModifier) / Shoot(Player, ...) / UseSpeedMultiplier(Player)）
- **灾厄孔雀翎（旧）**：仍由 PeacockModifier（GlobalItem）服务（灾厄弹幕/贴图），过渡兼容
- 两者通过 `MalachiteCache.IsMalachiteItem` 共享天赋/对话/命中钩子入口（家族识别）

### 核心类速查
| 类 | 职责 |
|---|---|
| `CalamityCompat` | 唯一接触灾厄的反射层（玩家潜伏、弹幕标记、DownedBossSystem 字段） |
| `ProgressSystem` | GetStage()（原版+灾厄锚点）、10 个灾厄 Boss 击杀查询 |
| `StealthSystem` | 潜伏值/判定/标记；灾厄在场读写灾厄，缺失用 MalachitePlayer.stealthValue |
| `MalachiteProgress` | ModSystem 存档：所有 Boss 击杀记录（为技能点铺路） |
| `MalachitePalette` | 全局调色板（Terraria 像素风 + 翡翠主题五色定位） |
| `AdditiveLayer` | additive 发光绘制辅助（Pixel = 自建 1x1 纹理） |
| `MalachiteDamageClass` | 自建伤害类：通用全继承 + 职业 25% 继承（用户设计） |
| `MalachiteCache` | Native* 本模组类型 + 灾厄 TryFind 软引用 + IsMalachiteItem/IsNormalProj/IsBolt |

### 弹幕
- `MalachiteProj`（普攻飞刀）：竖直刃贴图、残影 + 三层光晕、追踪、重力、命中中毒/瘟疫
- `MalachiteBolt`（潜伏射线）：extraUpdates=8 极速 + 12 残影光带 + 三层光晕 + 命中火花 + 穿透耗尽爆炸
- `OrbitingMalachiteProj`（浮游剑阵）：像素贴图 + Dust 轨道粒子
- `MalachiteDomain`（领域原型）：V 键触发，法阵 + 减速/迅捷 + 边缘粒子 + 收尾迸发

## 六、操作要点
1. **工作流**：只改工作区 → `dotnet build -c Debug` 编译自检（产物只在工作区 bin/obj；打包 tmod 到用户 Mods 被权限拒绝属正常，由作者同步 ModSources + 游戏内构建）
2. **同步**：作者自行把工作区同步到 `ModSources\可成长的孔雀翎`（注意 `Textures\` 全部 PNG 都要带过去）
3. **合规**：参考灾厄（Azafure, LLC + CalamityModPublic 链接）与 CWR（MIT, hocha113 + 链接）的文件已加头部署名；后续参考新仓库继续补
4. **存档兼容**：武器类名变更导致旧物品失效；后续大改动注意
5. **贴图占位**：MalachiteProjTex/BoltTex/OrbitingTex 为程序占位（用户将自绘替换同名 PNG）
