# 阶段 2b：独立成长曲线 + 「念」伤害类型（设计草案 v0 · 待拍板）

> 日期：2026-09-02 ｜ 关联：写法\阶段2_天赋星图重设计.md（星图=技能点加点系统）
> 定位：本系统**独立于星图之外**——孔雀柳刃的"基础属性成长曲线"（伤害/攻速/穿甲/潜伏多段）
> 按原版流程梯队设计，随 stage 自动成长；星图五轨只在其上做数值叠加，二者解耦。
> 角色设定：武器名 孔雀柳刃 / 伤害类型 重命名「念」（心灵/思念之意）。

---

## 1. 系统边界（与星图解耦）
- **独立成长系统 = 阶段基础曲线**：由 `stage(0..N) → {基础伤害倍率, 使用间隔, 护甲穿透, 潜伏倍率/齐射数}` 单一数据表驱动。
- 星图档案（TalentProfile）与「念」职业加成在**基础曲线之上**相乘叠加，但**不改基础曲线本身**。
- 曲线表建议从 MalachiteData 拆到独立数据服务（如 `Core\WillowGrowth.cs`），与 TalentModel 互不引用（星图更动不牵连成长）。

## 3. 成长曲线草案（绝对手感，非百分比堆）
实现模型：保留 `Item.damage=32 / useTime=20` 为“档位 0 基准”，
由 `WillowGrowth.ForStage(stage)` 返回该档「最终伤害系数 × 攻速系数」，替换现 14 元素表。

潜伏/穿甲段（草案）：FlatAP 0→35 平滑、潜伏倍率 0.8→2.5 已在位，随数值波次按新系数体系重标。

## 4. 「念」伤害类型（重命名 + 继承语义）
- 显示名：**念 / Mind**（内部类名建议保留 `MalachiteDamageClass` 以零存档/词缀迁移风险——是否连类名一起改，拍板 D13）。
- 继承语义（ModifierInheritanceData 权重 = 伤害% 与暴击% 等修饰的继承比例；攻速另行确认 D14）：

| 来源类型 | 权重 | 说明 |
|---|---|---|
| 通用（"全部伤害+%"） | **100%** | 原版 Generic：凡"全职业加成"全额生效 |
| 召唤伤害 | **100%** | 满额吃召唤饰品/召唤伤 |
| 近战伤害 | **25%** | |
| 远程伤害 | **25%** | |
| 魔法伤害 | 0% | 未点名，默认不继承 |
| 投掷(遗留) | 0% | |
| **其它模组任意伤害类型** | **25%** | 运行时对未知类返回 0.25 权重 → 以后装任何模组饰品/职业加成自动 25% 生效 |

- 攻速口径（待确认）：若按同套继承权重，则近战/远程攻速也只吃 25%、召唤攻速 100%、通用 100%。
  若你想要的是"任何来源的攻速加成全部全额生效"，需要单独口径：只把 **Generic+召唤+本类** 攻速计全额并排除他类，或用独立叠加函数——拍板 D14。
- 击退/护甲穿透等修饰：默认按通用全额 + 职业继承同权重；确认 D15。
- 词缀/减益继承沿用原 DamageClass 全继承设定（不改）。
- 实现：重写 `MalachiteDamageClass.GetModifierInheritance`（运行时按类匹配）；`DamageClasses.MalachiteDamageClass.DisplayName` hjson 改为 念/Mind；tooltip/UI 引用不变（经类常量）。
