## 铁律（写码前逐条过）

1. **签名纪律**：TML_2026_07 时代 ModItem hook 多为无 Item 参数签名；一切以本机编译为准，网上旧教程不可信。
2. **Dust 是 struct**：一律 `Main.dust[idx]` 直写字段；严禁 `Dust d = Main.dust[i]; d.x = …`（2026-09-05 扫仓 13 处教训）。
3. **视觉预算门只包粒子**：伤害 / 音效 / 状态变化严禁放进 CanSpawnEffect 门内（MalachiteBolt.Explode 教训）。
4. **多部件 Boss 键归组**：一律用 `MalachiteProgress.GetBossKey`（已内置双子/月总归组），勿自造键（否则一杀多发点数）。
5. **绘制纪律**：弹幕 PreDraw 优先画进引擎自身批次（Additive 用 AdditiveLayer）；任何换批次必须 try/finally 还原（当前三处换批次与铁律冲突待拍板，见 更新日志 2026-09-05）。
6. **合规**：复用外部代码前查 `references\合规定级速查.md`；A 级保留版权声明、G 级禁搬码、C 级署名+链接。
7. **文案/数值**：剧情文本每句需用户确认；数值表改动走决策门（决策文档是剧本）。
8. **旧资料甄别**：2018 年以前的论坛/教程（含官方帮助帖的技术细节）一律先过「时代性三问」（日期≥tML 1.4 时代 / API 在本机存在 / 与 ExampleMod 一致）；过时反例清单见 `写法\参考_tML官方帮助帖研读.md` §三，禁止照抄。
