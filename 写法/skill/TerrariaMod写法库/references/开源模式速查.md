# 开源模式速查（P1~P15 卡片）

> 出处级别：A=可复用（保留版权声明）；G=仅学模式禁搬码；C=仅研读署名+链接。全文与出处链接见 `写法\参考_开源mod库研读与模式提炼.md`。

## P1 伤害类五维继承权重（A · ExampleMod/Content/DamageClasses/ExampleDamageClass.cs L16-25）
StatInheritanceData 五维各 0~1（可负/>1）；Generic 永远单独 Full；官方 L26-52 有混合权重反例+无上限警示。
→ 孔雀翎 MindDamageClass 已同 API 且更细；补 SetDefaultStats 白值 + CommonItemTooltip 公共词条。

## P2 效果/词缀继承 + SetDefaultStats（A · 同文件 L55-73）
GetEffectInheritance 白名单（岩浆石/幽灵弹等触发装备）；SetDefaultStats 用 GetCritChance<T>() 给默认白值。
→ 念系默认暴击/护穿从武器 SetDefaults 迁至 SetDefaultStats。

## P3 武器挂接伤害类（A · ExampleCustomDamageWeapon.cs L13-24）
唯一入口 Item.DamageType = ModContent.GetInstance<T>()。官方坑：无 mana 消耗时除 Deranged 外的魔法前缀不可用。
→ 复查念系武器前缀池预期。

## P4 射击钩子族（A · ExampleGun.cs L61-66）
ModifyShootStats（改五项）→ Shoot（return false 阻止原版发射+手动扇形）→ CanUseItem/UseItem/HoldoutOffset；官方注释 6 模板（乌兹换弹/Vampire 扇形/枪口偏移/三连发/双弹种/随机弹种）。

## P5 长枪类复用（A · ExampleSpear.cs L40-43）
ItemID.Sets.Spears[Type]=true + noUseGraphic/noMelee + ownedProjectileCounts[Item.shoot]<1 + UseItem 内 dedServ 音效守卫。

## P6 PrimTrail 顶点闭环（A · SpiritMod/Prim/PrimTrail.cs L66-76）
Draw 四步：重建 VertexPositionColorTexture[] → PrimStructure 填点 → SetShaders → DrawUserPrimitives；构造时 dedServ Dispose；PrimTrailManager 半分辨率 RT 像素化。
→ AdditiveLayer 上叠顶点带生成器（复用须署名 Team Spirit）。

## P7 粒子池三闸门（A · SpiritMod/Particles/ParticleHandler.cs L65-75）
Server 丢弃 / 硬上限 500 / 配置开关；反射注册子类（类名=纹理路径）；按 Additive 分双批次绘制。
→ EffectLimiterSystem 同思路；借鉴预分配池替代逐次 NewDust。

## P8 UI 五件套（A · ExampleMod/Common/UI/ExampleCoinsUI/ExampleCoinsUISystem.cs L43-57）
Client 侧 Autoload → PostSetupContent 建 UI+Activate → UpdateUI 转发 → ModifyInterfaceLayers 插 Vanilla: Mouse Text 前 → SetState 开关；进阶 UIShaderImage（Immediate+UIScaleMatrix+ScissorTest）。

## P9 SyncPlayer 三件套（A · ExampleStatIncreasePlayer.cs L23-36 + Networking.cs）
SyncPlayer 写包 Send(toWho,fromWho) → HandlePacket 按枚举分发+Server 分支转发 SyncPlayer(-1,whoAmI,false) → SendClientChanges/CopyClientState 上报裁决。
→ D20 波次多人同步直接套此模板。

## P10 Packet 类体系 + ResendFromServer（C · WotG Core/Netcode/PacketManager.cs L44-58）
反射注册 Packet 类（FullName 索引）；客户端只发意图→服务器权威化→重发；同构参考 Overhaul NetPacket（G 级只看思路）。

## P11 hjson 组织惯例（A · ExampleMod/Localization/en-US.hjson L1-7）
根键 Mods.{ModName}.*；键自动生成；自定义伤害类必须有 DamageClasses.X.DisplayName；公共词条 CommonItemTooltip+{$...}；大模组拆多文件（SpiritMod 14/WotG 26）。

## P12~P14 Luminance 框架六模式（A · github.com/LucilleKarma/Luminance）
①类型安全 ModCall（ModCall.cs）②ManagedShader 参数缓存 ③MemberJit 版本门控（VersionAwareModJitAttribute.cs）④Pushdown 状态机 ⑤Detour/IL 集中注册+统一卸载（HookHelper.cs）⑥Shader 目录约定装载（ShaderManager.cs）。

## P15 StructureHelper 工具链五模式（C · github.com/ScalarVector1/StructureHelper）
门面+惰性缓存；GZip 资产（魔数头+Version+modded ID 存 FQN 重映射+文件名防冲突）；多态 TagCompound（Type 判别+switch 工厂）；反射 IoC UI 装配；RenderTarget 预览队列。
