## 署名头模板（A 级复用）

```csharp
// 代码来源与合规署名：
// - <模式名> 参考/复用自：<仓库名>（MIT License, Copyright (c) <年份> <版权人>）
//   <仓库链接> —— <文件路径>
// 复用段保留原版权声明与 LICENSE 文本；其余为自主实现。
```

## 红线

1. G 级（GPL/AGPL）代码进入孔雀翎 = 整体被迫 GPL 开源——**任何情况下不搬运**。
2. C 级只产出「思路笔记」（笔记同样署名+链接）；需要片段先向作者确认。
3. 新增参考仓库必须同步：本文档定级表 + description.txt Credits + 文件头署名（工作流 R8）。

## 新增仓库流程

实读 LICENSE（github_file_read）→ 按 A/G/C 定级（Wiki 协议≠代码协议）→ 登记本文档 → 按级别执行复用口径。
