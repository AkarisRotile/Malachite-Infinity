# 安装为会话级 skill（可选）

本项目内 skill 已按 DSH filesystem skill 的结构组织（根 `skill.md` + `references\`）。
若你希望它在**每个会话的 skill 目录**里被自动发现（像 game-art-guide 那样出现在会话技能列表），由作者在本机执行一次复制：

```
把  E:\孔雀翎\写法\skill\TerrariaMod写法库
复制到  %USERPROFILE%\.dsh\skills\terraria-mod-patterns
```

说明：
- 现有 skill（如 code-quality-workflow）即从该目录加载，复制后下次会话即可见；
- 沙箱内代理无权写工作区外目录，此步骤需作者手动完成；
- 复制后两处内容会分叉——约定：**工作区版为唯一权威**，升级后重新复制覆盖即可。
