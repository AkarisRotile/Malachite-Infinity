## 2. 星网结构

### 2.1 三类星

| 类型 | 形状 | 半径 | 辉光层 | 消耗 | 数量 |
|---|---|---|---|---|---|
| ✦ 星尘 `Dust` | 正菱形 4×4 | 3px | 0 | 1 点 | 20 |
| ✧ 星宿 `Asterism` | 正八边形 8×8 | 6px | 1 | 2 点 | 10 |
| ★ 星核 `Nucleus` | 四角星芒 16×16 | 10px | 2（底层旋转 45°） | 5 点 | 5 |
| ◉ 翎心 `Root` | 十二角芒 + 双环 | 14px | 3 | 免费（初始点亮） | 1 |

**共 36 节点，全解锁成本 = 20×1 + 10×2 + 5×5 = 65 点**，而全 Boss 首杀 + 事件里程碑约 46 点 → **必须取舍，构筑才有意义**。

### 2.2 几何布局

- 画布 340×340，中心 `(210, 260)`（面板绝对坐标），渲染半径 `R = 170px`。
- 5 条臂，角度 `A(k) = -90° + 72°k`（屏幕坐标，y 向下）：
  `k0 攻(正上)` / `k1 穿(-18°)` / `k2 速(54°)` / `k3 暴(126°)` / `k4 念(198°)`。
- 每条臂由内向外链：`D1(r=0.30) → D2(r=0.50) → S1(r=0.68) → D3(r=0.84) → N1(r=1.00)`。
- 两圈环向连线（臂间中点，角度 `A(k)+36°`）：
  - 内环 `R1`（r=0.40，星尘 ×5）串起各臂 D1
  - 外环 `R2`（r=0.76，星宿 ×5）串起各臂 S1 ⟶ **跨臂混搭的通路**

### 2.3 点亮规则（邻接连通）

- `Root` 初始已点亮；其余节点必须与**至少一个已点亮节点之间存在边**才可购买。
- 右键单点退还：退还后若导致任一已点亮节点失去全部通路，**拒绝并提示**。
- 「一键洗点」：全部退还为点数，`Root` 保留。
- 击杀门槛节点：门槛未达成时图上显示"需击败 XXX"，即使相邻也**不可购买**。

## 4. 视觉规格（AGY 咨询稿 · 冲突时以 AGY 为准）

> 来源：`写法\_agy\reply_01~03`（模型 `agy-gemini-3.8-flash-low`，经 `写法\_tools\ask-agy.mjs` 串行调用）。
> **配色优先级（2026-09-27 用户拍板）**：AGY 稿与既有调色板冲突时**以 AGY 为准**。
> 落实方式：AGY 的色值**收编进 `MalachitePalette`** 具名条目（`StarCardBg` / `StarCardBorder` /
> `StarCardBorderDim` / `StarInk` / `StarInkDim`），不是就地硬编码 —— R5 的"集中"精神保留，色值取向解禁。
> 星网节点/连线用色（`#3DDC84/#7CFFB8/#1E7A46/#124228/#FFD54F/#4FD8E8/#E8F5E9`）与主调色板同值，直接复用。

### 4.1 节点四态

| 状态 | 表现 |
|---|---|
| 未点亮 | 实心 `GreenDark`，边 `GreenDeep`，alpha 200（保证可见——历史事故③）。**无任何辉光** |
| 可购买（相邻且点数够且门槛达成） | 边/环 `GreenBright` 1Hz 呼吸，alpha 120→255 |
| 已点亮 | 实心 `PrimaryGreen` + 1px `TextLight` 白芯 + Additive 辉光 `GreenBright`（星核用 `AccentGold`） |
| 悬停 | 整体放大 1.25×，+1px `AccentCyan` 外廓 |

> **★ 2026-09-27 修正（离线像素实测）**：
> ① **未点亮星核曾经自带光环** —— 原实现给未点亮的星核套了一圈 `AccentCyan · 0.32`，
>    后果是"只点亮翎心的新档"一开星图就有 5 枚青色光斑，读起来像已激活。现改为只有"可购买"才给亮环。
> ② **未点亮星核中心曾是纯白点** —— `PrimitiveVfx.StarSpikes` 的每根芒都是"从中心发散的三角形扇"，
>    两层四芒 = **16 个三角形共用同一个中心顶点**，加色混合下 `GreenDark×16` 直接钳制成白（实测 `(145,255,255)`）。
>    修法：给 `StarSpikes` 增加可选 **`holeRadius`**（根部内孔），未点亮取 `r×0.62 / r×0.42` 把根部散开。
>    修后实测：未点亮中心 `(12,18,20)`＝背景；点亮中心由死白 `(255,255,255)` 变为暖白 `(191,204,180)`，金色得以透出。

### 4.3 加点动效（60 FPS）

- 流光推进 **12 px/帧**（每段时长 = 段长 / 12，向上取整）。
- 流光体：总长 24px、宽 3px；头 4px `White` a255，尾 20px `GreenBright` a255→a0，两端渐细至 1px，Additive。
- 落点爆闪：**16 帧**；冲击波半径 8→28px（Ease-Out），`GreenBright`→`PrimaryGreen`，alpha 255→0；
  星核额外叠一圈 `AccentGold`（r 36px）；**仅星核**触发微震屏 2px / 6 帧。
- 音效 3 层：出发 `MenuTick` → 沿途升调 → 落点清脆铃音（星核加延迟 2 帧的低音）。
- 多路同时点亮：同源分流并发推进，每通道音量 ×0.7，爆闪各自独立。

- **星网渲染中心 = (210, 275)**（画布局部 `(170, 185)`），**渲染半径 R = 155**。
- ★ 为什么中心不是画布正中 (210, 260)：五臂角度 `A(k) = −90° + 72°k`，**没有任何一臂朝正下**，
  墨迹的 y 范围是 `[−1.0, +0.809]·R` —— 天生偏上。让**中心点**居中会变成"顶部出界、底部空一截"；
  正确做法是让**墨迹**居中：`centerY = 170 + (1.0 − 0.809)/2 · R = 170 + 0.0955R ≈ 185`。
- R 取 155（而非 170）是让节点自身的视觉外延（星核芒 ≈20px）也留在画布内。
- **实测包围盒**（离线渲染逐像素量测 fx_35）：墨迹 `334×319`，中心 `(209.5, 260)` vs 画布中心 `(209.5, 259.5)`——
  **居中误差 0.5px，四边零溢出**（上 11 / 下 10 / 左右各 3 px 留白）。
  修正前：顶部溢出 19px、底部空 30px。
- 详情卡占 x>392 空白区，与星网（x ≤ 380）**零重叠**。

## 5. 求值模型

`TalentProfile` 由「五轨等级」改为「**已点亮节点集 → 汇总**」：

```
TalentProfile {
    float DamageMult;          // 星尘累加
    int   ArmorPen;
    float AttackSpeedMult;
    int   CritChanceBonus;
    int   VolleyBonus;         // 并发轨等效值（双生并发使之翻倍）
    float CritOverflowRate;    // 暴击溢出增幅系数（过载暴击 / 盈满之念改写）
    StarFlag Flags;            // 质变标志位（星宿 / 星核）
}
```

`StarFlag` 为 `[Flags]` 枚举，武器/近战/弹幕层只做 `HasFlag` 判定，禁止再出现散落条件。
