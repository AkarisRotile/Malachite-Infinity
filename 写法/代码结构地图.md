## 一、顶层布局

| 路径 | 作用 |
|---|---|
| mod本体\tModLoader.targets | 指向 Steam tModLoader 的 tMLMod.targets（仅工作区 dotnet 编译自检用，已确认保留） |
| mod本体\可成长的孔雀翎\ | 模组源码主体：29 个 .cs ≈ 5730 行（2026-09-03 快照） |

模组定位：**独立成长向模组**（编译/运行零灾厄依赖）。
玩法 = 一把会陪你成长的孔雀柳刃：砍树掉落 → 阶段成长曲线 × 五轨加点 × 潜伏 ×
**近战形态（ES 流 v6.4/6.5）** + 对话陪伴线（丛林刃灵"她"）。

## 二、运行时模块协作（一张图）

    砍树掉落 → 孔雀柳刃 (Items/PeacockWillowBlade)
        │
        ├─ 成长数值：WillowGrowth(阶段表) × TalentEvaluator(五轨档案) → ModifyWeaponDamage
        │            阶段锚点 = ProgressSystem.GetStage()（纯原版 Boss 链，无灾厄）
        ├─ 左键远程：MalachiteProj(飞刀)/MalachiteBolt(潜伏射线)
        │            潜伏 = StealthSystem(25%阈值) → 扇形齐射（念伤害 MindDamageClass）
        ├─ F 近战（ES v6.4）：MalachitePlayer.PreUpdate 八向输入判定树
        │            → MalachiteMelee(参数/矩阵唯一出处) → MeleeSlashProj(状态机/物理/取消/刀光)
        │            → EsCrestSigilProj(空间纹章：SetupCrest 参数契约)
        ├─ 命中层：MalachitePlayer 钩子 = FlatAP(WillowGrowth) + 档案穿甲；近战命中叠「精准」
        └─ 陪伴线：Boss 击杀(MalachiteProgress 世界档) → 里程碑对话 / 日常闲聊 / 死亡彩蛋
                    UI 冻结区(MalachiteUI) 只播 DialogDatabase 的 DialogGroup

## 五、维护要点（历次会话验证过的坑，务必传达）

1. 同步 = 全量镜像：ModSources 每次复制新增/修改并删除已移除文件；新增文件（如 Core\MalachiteMelee.cs）易漏。
2. 世界内热重载会崩：他人模组绘制钩子在我模组卸载瞬间访问失效手持物品 → 空引用；回主菜单再 Build&Reload。
3. 门禁 PS5.1 读文件为 GBK：Projectiles 下中文署名头文件若被写成"无 BOM UTF-8"会误报"无署名"——该目录文件保持 UTF-8 BOM（EsCrestSigilProj.cs 曾因此 WARN 一次）。
4. 渲染铁律：弹幕 PreDraw 特效画进引擎自身批次（world−Main.screenPosition）；顶点扇形条带用 Additive、View=GameViewMatrix.TransformationMatrix、结束严格还原 AlphaBlend；禁 MagicPixel。
5. 调参集中：近战全部参数唯一出处 = Core\MalachiteMelee.cs（常量 + CrestSpecOf 矩阵）；成长曲线 = WillowGrowth；天赋数值 = TalentModel；配色 = MalachitePalette。
6. 决策文档是"剧本"：新机制/数值大改先读对应设计文档对齐（D 编号决策），改剧情文案每句需用户确认。
