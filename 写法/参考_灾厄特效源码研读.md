## 二、粒子体系（我们最该学的部分：纯 sprite 即可做到高级观感）

### 2.1 基类与生命周期
- 基类 Particles/Particle.cs：注册 ID + 字段 Position/Velocity/Color/Scale/Rotation/Lifetime；子类覆写钩子。
- 关键虚成员（各粒子类覆写）：
  · `Update()`：每帧改 Scale/Color/Velocity（衰减、重力、自旋）；
  · `CustomDraw(spriteBatch,...)`：自绘（可多层绘制）；
  · `UseAdditiveBlend => true/false`：粒子级选加色/普通混合；
  · `SetLifetime`/`Important`：寿命推进 / 重要粒子不因数量限制被吞。
- 总管 GeneralParticleHandler：注册全部粒子类、管理世界/屏幕两套、按各自 UseAdditiveBlend 归批，在固定绘制层 flush。

### 2.2 素材方法论（重要！他们的"光"基本是一族拉伸贴图）
- 素材家族：BloomCircle / BloomRing(含 Angled/ThinLarge) / BloomLine(5+ 变体)/ BloomArrow / CircularSmear(多套) / CircularTrail / Streak / Sparkle / Light / BrightFlash —— 都是画好的一张柔和光斑/线段，靠"拉伸+旋转+多层"复用，不是每次造几何。
- **双层绘制 = 彩色底层 + 白热芯**（CustomSpark/ChargeUpLineVFX 同款）：
  先画 彩色×α 且放大 ~1.1x 的"外晕"，再叠 白/白热×α 的"芯"（可再小 0.8x）。发光体瞬间有"热核"层次。
- **沿速度拉伸**：Rotation = 速度角 + 90°，非等比 Scale=(Stretch.X, Stretch.Y) → 火花/拖尾有方向性。
- **淡出不是线性**：Color = Lerp(初始, Transparent, pow(寿命进度, 3))（伽马型急落）；Scale 每帧 *=0.95 缓缩或按寿命曲线。
- 可选受光照：AffectedByLight 时用 Lighting.GetColor 乘色——特效也能"随场景明暗"（通常关闭以保亮）。
- 像素化：Pixelate 时走 PixelationManager.AddPixelatedDrawer(层, 混合)（RT 方案，我们暂不用）。

### 2.3 动效曲线工具
- CalamityUtils：CurveSegment(缓动类型, 起点时间, 起点值, 斜率) + PiecewiseAnimation(进度, 段数组) → 分段关键帧动画（例：先退 0.25s 再 SineIn 冲出、挤压-回弹）。
- 我们目前用 smoothstep/爆发过冲曲线，可扩展成"分段关键帧"做蓄力/回弹类特效。

## 三、拖尾/斩痕的两种正宗做法（对照我们 v5 系列问题）

### 3.1 sprite 粒子流（特莉波卡/熵系，我们已在其仓库学到）：历史采样 → 扇形条带
- 挥动每子帧把 (旋转角, 刃长刻度) 推入环形缓冲（cap~170）；每帧用缓冲画顶点条带（内缘→外缘），彩色主带叠白热芯，渐变 uv + 时间动画。
### 3.2 通用顶点管线（灾厄 PrimitiveRenderer）
- 接口：`PrimitiveRenderer.RenderTrail(List<Vector2> 世界坐标轨迹, PrimitiveSettings 设置, 细分点数)` —— 自动减 Main.screenPosition、平滑插值、渐变 uv、可选圆帽/封口，配 shader/贴图/混合由 PrimitiveSettings 指定。
- 像素化拖尾必须让实体实现 IPixelatedPrimitiveRenderer 并从 RenderPixelatedPrimitives 提交（有断言检查）。
- Effects/ 特供 shader 与用法示例：ExobladeSlashShader(刀光渐变)/ArtAttackTrail/FadedUVMapStreak/FadingSolidTrail/DoG 系/火焰等；CalamityShaders.cs 统一装载。
- 说明：顶点管线能做出最"扎实"的弧光，但依赖 fx 资产与绘制层纪律；我们暂不引入 shader 管线（R6 约束 + 无 fx 编译链），先用 sprite 段带（我们的 1x1 Pixel 拉伸段）达到近似观感，瓶颈主要在浓度/层次/采样贴合，而非绘制方式。

## 四、打击反馈套装（从 Devil's Devastation 等武器代码归纳）
- 命中 → 一撮"套装"：白热爆点(CustomSpark 白)+ 沿切线飞散火花(AltSpark/LineCal)+ 扩散环(CustomPulse/DirectionalPulseRing/BloomRing)+ 一道斩痕闪(PRT_MultiSlash/ShineParticle)+ 低音命中音 + 屏幕微震。
- 屏幕震动：Player.SetScreenshake(强度) 扩展（随距离/强度衰减，客户端本地）；Terraria 无原生 API，须自己实现或不做（我们暂缓）。
- 反馈是"套餐化"的：一次命中只精心演一次，而不是每种尘都撒一点。

## 五、落地到本 mod 的可执行清单
1. **热核双层**：所有亮体（曳光带/火花/环）先彩色×1.1x 后白芯——我们的 DrawSeg/贴图已可按此加一层（成本低，观感提升大）。
2. **沿速度拉伸的火花**：把命中切线火花从"点尘"改为沿速度拉长的短线段/贴图（有 Stretch 语义）。
3. **伽马淡出**：把环/带 alpha 衰减从线性 lerp 换成 pow(寿命,~2~3) 的急落。
4. **扇形条带采样贴合**（近战拖尾核心）：拖尾带必须与刃身用**同一条曲线**采样、且覆盖"整段已走路径"并叠白芯——v5.3 已按此改（历史见更新日志）。
5. **素材族规划**：若要继续堆特效，先出一套自己的 BloomLine/BloomRing/CircularSmear 白描贴图（或沿用 MeleeSlash 画法），避免每处另造几何。
6. **粒子管总**：现阶段用 EffectLimiterSystem + Dust/自绘，未引入 Calamity 粒子框架（避免依赖与许可负担）；后续若粒子种类多，可自建轻量"粒子+分层总管"（参考其分层/加色/Important 语义，自主实现）。
7. **暂缓**：fx shader 管线 / RT 像素化 / 屏幕震动——留到需要时再评估，不因观感而提前负债。
